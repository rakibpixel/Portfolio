Getting started

Up and running in minutes

Install once in each app, open the panel, and start pushing. No account, no subscription.

01

Install & enable

Unzip and run the Windows or Mac installer. It drops into the Adobe CEP extensions folder and flips the debug switch for you.

02

Open the panel

In Photoshop, Illustrator or After Effects: Window → Extensions → AE Bridge. The panel docks to your workspace.

03

Select & push

Pick layers or artwork, hit Push to After Effects. Text, vectors, groups and blend modes all come along.

04

Animate

Everything lands in a matching comp, positioned and editable. Open the precomps, keyframe, and go.

FAQ

Questions, answered

The essentials — a full guide ships inside the download too.

How do I install it?+
Unzip the package and run Install_Windows.bat or Install_Mac.command. It copies the AEBridge folder into the Adobe CEP extensions directory and enables extension debug mode automatically. Restart your apps, then open it from Window → Extensions → AE Bridge. To remove it later, run the matching Uninstall script.
Which apps does it work in?+
One install runs in Photoshop, Illustrator and After Effects. The panel detects the host app and adapts — push from Photoshop or Illustrator, and After Effects imports automatically.
Does text stay editable in After Effects?+
Yes. Type layers become real After Effects text layers with the same content, font, size and color — fully animatable, not rasterized.
What comes through from Illustrator?+
Vector paths arrive as native shape layers with real bezier points, fills and strokes. Compound paths and groups are preserved; groups become precomps. Anything non-vector (symbols, placed images) comes through as a clean raster.
What about Photoshop layers?+
Text stays editable; everything else (including shape and adjustment-heavy layers) arrives as lossless raster so your look is identical — and each layer keeps its blend mode.
Will elements stretch or distort?+
No. By default After Effects builds a new comp matching your document size, so everything lands 1:1. Push into an existing comp and oversized art scales to fit the width — never stretched.
Is it a subscription?+
No. AE Bridge is a free download — grab it, install it, and it's yours. Runs fully on your machine.
