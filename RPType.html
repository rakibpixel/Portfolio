৪ ধাপে চালু করুন

পুরো প্রক্রিয়াটি দুই মিনিটেরও কম সময়ের।

01

ফাইলটি আনজিপ করুন

ডাউনলোড করা RP-Type.zip ডাবল-ক্লিক করে খুলুন। ভেতরে keylayout ফাইল ও ইনস্টলার পাবেন।

02

ইনস্টলার চালান

install_RP-Type.command ফাইলে রাইট-ক্লিক করে Open বেছে নিন (শুধু ডাবল-ক্লিক নয়)। এটি স্বয়ংক্রিয়ভাবে লেআউটটি সঠিক জায়গায় বসিয়ে দেবে।

প্রথমবার

"Apple could not verify…" বার্তা এলে?

চিন্তার কিছু নেই — এটি ফাইলের কোনো সমস্যা নয়। যেহেতু এটি একটি ফ্রি, ওপেন লেআউট (Apple-এ পেইড সার্টিফিকেট ছাড়া), macOS প্রথমবার নিরাপত্তার জন্য জিজ্ঞেস করে। নিচের যেকোনো একটি উপায়ে খুলুন:

  1. ওই বার্তায় Done চাপুন (Move to Trash নয়)।
  2. Finder-এ install_RP-Type.command ফাইলে রাইট-ক্লিক (বা Control + ক্লিক) করুন।
  3. মেনু থেকে Open বেছে নিন — এবার বার্তায় একটি Open বাটন থাকবে, সেটি চাপুন।

বিকল্প: System Settings → Privacy & Security → নিচে স্ক্রল করে "Open Anyway" চাপুন। একবার অনুমতি দিলে পরে আর জিজ্ঞেস করবে না।

03

Mac রিস্টার্ট করুন

নতুন লেআউট চিনতে macOS-এর একবার রিস্টার্ট (বা লগআউট → লগইন) প্রয়োজন।

04

কীবোর্ড যোগ করুন

System Settings → Keyboard → Text Input → Edit… এ যান → + → Bangla → RP-Type বেছে নিন। ব্যস! মেনু-বার বা Ctrl + Space দিয়ে সুইচ করুন।

বিকল্প উপায়

ম্যানুয়াল ইনস্টল

কোনো সতর্কতা ছাড়াই — installer চালাতে না চাইলে।

  1. Finder খুলে মেনু থেকে Go → Go to Folder… (বা Shift + Cmd + G)।
  2. এই পথটি লিখে Enter চাপুন: ~/Library/Keyboard Layouts
  3. RP-Type.bundle ফোল্ডারটি টেনে এই ফোল্ডারে রাখুন।
  4. Mac রিস্টার্ট করে উপরের ধাপ ৪ অনুসরণ করুন।

আইকন দেখতে চাইলে .bundle ব্যবহার করুন — শুধু .keylayout ফাইল দিলে macOS ডিফল্ট আইকন দেখায়।

দ্রুত সুইচ

🌐 বাংলা ↔ ইংরেজি টগল

Globe বা Fn বাটন চেপেই ভাষা পাল্টান।

  1. System Settings → Keyboard খুলুন।
  2. "Press 🌐 key to" অপশনটি "Change Input Source" এ সেট করুন। এবার 🌐 চাপলেই বাংলা ↔ ইংরেজি পাল্টাবে।
  3. নিজের শর্টকাট চাইলে: Keyboard Shortcuts… → Input Sources → "Select the previous input source" এর কী বদলান (ডিফল্ট Ctrl + Space)।

টিপ: দ্রুত টগলের জন্য মাত্র ২টি ইনপুট সোর্স রাখুন — English ও RP-Type।
