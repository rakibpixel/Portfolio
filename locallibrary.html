FAQ

Questions, answered

The essentials, tap-to-expand. A full guide ships inside the download too.

How do I install it?+
Unzip the package and run Install_Windows.bat or Install_Mac.command. It copies the LocalLibrary folder into the Adobe CEP extensions directory and enables extension debug mode automatically. Restart Photoshop or Illustrator, then open it from Window → Extensions → Local Library. To remove it later, run the matching Uninstall script — your workspace folder and saved assets are never touched.
Where are my assets actually stored?+
In a workspace folder you choose on your own computer. Each library becomes its own subfolder, and files are kept at original quality with no compression. Because it's a normal folder, you can back it up, sync it, or move it like anything else — and uninstalling the extension leaves all your files in place.
Does it really work in both Photoshop and Illustrator?+
Yes. One install runs in both. The panel detects the host app and adapts: From App exports a Photoshop layer or an Illustrator selection, and placing drops the asset into whichever app you're in. Vector assets stay editable vectors in Illustrator; in Photoshop you choose an editable layer or a Smart Object.
What can I store?+
Images and graphics (PNG, JPG, SVG, WebP, PDF, AI, EPS) at any size, plus solid colors that apply as your foreground color instantly, and text styles that save font, size and color as reusable presets.
How do I place an asset?+
Double-click an asset, or drag it from the panel onto the canvas. By default it arrives as a fully editable layer; right-click and choose Place as Smart Object if you'd rather keep it wrapped. Exports and placement are cleaned up so you don't get stray empty layers.
Can I move my libraries to another computer?+
Yes — use Export (.json) on a single library or all of them, copy the file (and your workspace folder), then Import (.json) on the other machine. Your libraries and ordering rebuild in seconds. Great for setting up a new laptop or sharing a kit with a teammate.
Is it a subscription?+
No. Local Library is a one-time license key — buy once, use forever, on your machine, fully offline. No monthly fees and no Creative Cloud account required.
