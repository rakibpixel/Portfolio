Full guide

Every tool, explained

The complete RP-Bar documentation — tap any tool to expand what it does and exactly how to use it.

Getting startedThe basics. +

The panel is a vertical strip of icons. Hover any icon to see its name and shortcut. Click to run. Some tools open a small floating window for extra options; others run instantly.

Shift shortcuts. A few icons do two things — a normal click does one, Shift + click does another. Watch the tooltip; it tells you both.
Reorder the bar. Drag any icon up or down to rearrange the toolbar however you like. Your order is saved automatically and remembered next time Photoshop opens.
CreateShape from Artboard +

Drops a rectangle shape filled with your foreground color, sized to the active artboard.

How to useClick to create a full-cover shape that matches the artboard exactly.

Click — full-cover shape  ·  Shift + Click — opens a window to set custom padding (an even margin on all sides)
CreateArtboard Resize +

Resize the canvas to a preset or a custom size, with control over which edge stays anchored.

How to useOpen the tool, pick an anchor (Center, Top-Left, Top-Center), then choose a preset (1080×1080, 1080×1920, etc.) or type a custom width and height and hit Resize.

CanvasTrim to Content +

Crops the canvas down to your visible artwork in one click — no more manual cropping when there's empty space around your shapes or images.

How to useJust click the icon. The canvas snaps to the bounding box of everything visible, trimming all four sides at once. This is the same as Image > Trim, but instant.

Good to know: works on transparent areas, and falls back to the top-left pixel colour for flat backgrounds.
CreateDuplicate & Offset +

Duplicates the active layer and nudges the copy by an exact pixel offset — handy for stepped repeats.

How to useSet the X and Y offset in pixels, then click Duplicate & offset. Repeat to step more copies in the same direction.

LayersRename Layers +

Rename many selected layers at once — as a prefix, a full name, or a suffix, with optional sequential numbering.

How to useSelect multiple layers in the Layers panel, type your text, pick Prefix, Name, or Suffix, then Apply. Prefix adds text to the front of each existing name; Suffix adds to the end; Name replaces the whole name.

Numbering: tick Number them to append a running count — with Name mode and text "BG" you get "BG 1, BG 2, BG 3…". Set the start number if you don't want to begin at 1.
Hand-offSend to Illustrator +

Push selected Photoshop layers straight into Illustrator as native, editable artwork — the same idea as the Overlord plugin, built right into RP-Bar.

How to useOpen Illustrator, select one or more layers in Photoshop, then click Send. Your art lands in the active Illustrator document (a new one is created if none is open).

What transfers, and how: Text layers become editable Illustrator text (font, size, colour). Shape and image layers come across as placed PNG images (pixels). Groups stay grouped. For a fully editable vector shape, use the Copy Vector button instead, then paste in Illustrator with Ctrl+V.
Copy Vector: copies the selected shape layer as SVG to the clipboard. Switch to Illustrator and press Ctrl+V — it pastes as a native, editable vector path with all its curves intact. This is the most reliable way to move a shape across as true vector.
Requirements: Illustrator must be installed and running for Send. The first send may take a moment while Illustrator wakes up.
SetupInstall Shortcuts +

Install a Photoshop keyboard-shortcut set (.kys) in one click — including the bundled RP-Bar set with a ready-made Copy SVG shortcut.

How to useClick Install RP-Bar shortcuts to drop in the bundled set, or Install a .kys file to load one from your computer. Then restart Photoshop and choose the set under Edit ▸ Keyboard Shortcuts ▸ Set.

Why it helps: the bundled set assigns Copy SVG to Shift+Ctrl+C, so you can copy any shape and paste it into Illustrator as an editable vector — the most reliable shape hand-off.
LayoutGrids +

A full grid and guide system — columns, rows, margins, plus quick shortcuts for centering and edge guides.

How to useTurn on Columns and/or Rows, set count and gap, and optionally add margins (L / T / B / R). Click Create guides to lay them down, or Clear all guides to remove every guide.

Shortcut row (left → right): center guide vertical · center guide horizontal · center both · center layer H · center layer V · guides around selected layer · render grid as shapes
Guides around a layer: select any layer and click the edge-guides shortcut — four guides snap to its bounding box.
WorkflowMiddle-Button Pan +

Pan the Photoshop canvas by holding the middle mouse button and dragging — the same way Illustrator does it. No more reaching for the Space bar.

How to usePhotoshop has no built-in middle-button pan, so this tool generates a tiny AutoHotkey script that maps the middle button to Space + drag (the Hand tool). You set it up once and forget it.

Save script to Desktop — writes RP-Bar_Pan.ahk  ·  Copy script — copies the text so you can paste it into your own file
One-time setup (Windows): 1) Download AutoHotkey v2 and install it. 2) Double-click RP-Bar_Pan.ahk — a green “H” tray icon appears. 3) Hold the middle button in Photoshop and drag. To auto-run on startup, press Win+R, type shell:startup, and drop a shortcut to the file in that folder.
macOS: AutoHotkey is Windows-only. On a Mac the same effect needs a tool like BetterTouchTool — ask and a guide can be added.
ConvertConvert & Rasterize +

One icon handles three conversions — wrap layers into a smart object, unpack them back, or flatten to pixels.

How to useSelect one or more layers, then:

Click — convert to smart object

Shift + Click — convert back to layers (unpacks a smart object)

Alt + Click — rasterize (flatten to pixels — works on smart objects, shapes, and type)
LayersReverse Layers +

Flips the stacking order of whatever you've selected — layers, groups, or artboards.

How to useSelect two or more items in the Layers panel, then click. Their order is reversed — the top goes to the bottom and vice-versa. Other layers stay put.

CleanupDelete Hidden Layers +

Removes every layer whose visibility is turned off, across the whole document.

How to useJust click. Every hidden layer is deleted; visible layers are untouched.

CleanupEmpty Layer Cleanup +

Deletes empty pixel layers that add clutter and file size.

How to useClick to scan and remove zero-pixel raster layers from the document.

ViewToggle Guides / Rulers +

Show or hide guides and rulers without digging into the View menu.

Click — toggle guides  ·  Shift + Click — toggle rulers
ExportExport Artboards +

Exports your artboards as image files with full control over naming — including a prefix, which Photoshop's own Export As can't do.

How to useOpen the tool. Every artboard appears in a checklist — all selected by default. Uncheck any you don't want, or use the all / none links. Pick a naming mode, format, and destination folder, then click Export selected.

Prefix / Suffix — names become prefix + artboard name + suffix (e.g. AD_Home_final)

Rename all — ignores artboard names; files become base + number (e.g. Ad_01, Ad_02)
Format: choose PNG or JPG. For JPG, a quality slider appears. Files save to the folder you pick, and illegal filename characters are removed automatically.
